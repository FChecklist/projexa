# PROJEXA AI Link (browser extension, Audit 37 point 36)

Chrome/Edge extension (Manifest V3, no build step, no network access). It makes the external-AI path one click inside a chat AI.

1. In PROJEXA click **AI prompt - paste in any AI** (it copies the prompt that contains your AI work link).
2. Click the extension icon, press **Paste from clipboard** (saved once, in the extension's own storage).
3. On ChatGPT, Claude, Gemini, DeepSeek or z.ai an orange **PROJEXA** button appears. Click it: the prompt is placed in the chat box. You press send.

Install for testing: `chrome://extensions` -> Developer mode -> Load unpacked -> this folder.
Roles and "no coding" are enforced by the work link itself on the server, not by this extension. The extension never sends anything anywhere.
